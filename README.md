# 🛒 KroyGhor SuperShop Management System

A PHP and MySQL-based **SuperShop Management System** developed to manage products, categories, customers, suppliers, users, and sales efficiently. The system provides a simple and user-friendly interface for performing daily supermarket management tasks.

---

## 📌 Features

- 🔐 User Authentication & Role Management
- 👥 Customer Management (CRUD)
- 🏷️ Category Management (CRUD)
- 📦 Product Management (CRUD)
- 🚚 Supplier Management (CRUD)
- 👤 User Management (CRUD)
- 🔍 Search & Filter Records
- 🗑️ Soft Delete Support
- 📊 Dashboard
- 📝 Form Validation
- 🎨 Responsive Admin Panel

## ⚙️ Installation

### 1. Clone the repository

```bash
git clone https://github.com/your-username/KroyGhor-SuperShop.git
```

### 2. Move the project

Copy the project into your XAMPP `htdocs` folder.

Example:

```
C:\xampp\htdocs\KroyGhor-SuperShop
```

or

```
G:\xampPHP\New folder\htdocs\KroyGhor-SuperShop
```

### 3. Create Database

Open **phpMyAdmin**

Create a database named

```
kroyghor_supershop
```

Import the provided SQL file.

---

### 4. Configure Database

Update your database connection file with your credentials.

Example:

```php
$host = "localhost";
$user = "root";
$password = "";
$database = "kroyghor_supershop";
```

---

### 5. Run the Project

Start

- Apache
- MySQL

Visit

```
http://localhost/KroyGhor-SuperShop/
```
